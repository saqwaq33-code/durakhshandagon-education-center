# Durakhshandagon Education Center

A multilingual educational website built with React + TypeScript + Tailwind CSS.

## Features
- React Router based navigation
- Tajik / Russian / English language switching
- Responsive UI for mobile, tablet, desktop
- Reusable components for courses, testimonials, contact form, and profile

## Run
```bash
npm install
npm run dev
```

## Validate
```bash
npm run lint
npm run build
```
